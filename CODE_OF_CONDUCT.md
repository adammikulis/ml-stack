# Code of conduct

Be respectful and keep discussion about the work. Harassment, personal attacks and discrimination are not
welcome in issues, pull requests or discussions.

Maintainers may edit, hide or remove contributions that break these rules and may block repeat offenders.
Report problems to the maintainer through the contact address on the GitHub profile of `@adammikulis`.

Adapted in spirit from the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
