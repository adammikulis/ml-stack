# ml-stack-contracts

The data several ml-stack packages agree on -- model tiers, the sampler
schema, grammars -- and the reader for it. No dependencies, so anything can
read the contract without pulling in a framework.

## Install

```
pip install ml-stack-contracts
```

Part of [ml-stack](https://github.com/adammikulis/ml-stack): train and run models across every machine on
your network.
